# pi-stuff

This repository contains Pi extensions and skills. Packages live in `packages/`; shared skills live in `skills/`.

Follow the conventions of the package being changed. Read relevant code and load skills or reference docs as needed; choose verification proportional to the change and report any material gaps.

Prime Lab guidance applies only to verifiers environment work, not to the extension monorepo. For that work, use the environment skills and `environments/AGENTS.md`; prefer the installed verifiers v1 APIs and keep legacy APIs separate.

The Prime-managed `AGENTS.md` is retained for synchronization. Pi loads this file instead.
