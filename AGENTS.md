# pi-stuff

This repository contains Pi extensions and skills. Packages live in `packages/`; shared skills live in `skills/`.

This repository is public. Never commit private or company information: no company, org or internal service names, colleague names, email addresses, account names, project IDs, internal URLs, local paths such as `/Users/...`, or secrets. Use generic wording and examples, and take machine-specific paths from environment variables or arguments. Check the diff for these before every commit.

Follow the conventions of the package being changed. Read relevant code and load skills or reference docs as needed; choose verification proportional to the change and report any material gaps.
